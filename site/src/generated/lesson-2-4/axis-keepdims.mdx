```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])

s = A.sum(axis=1, keepdims=True)
print(s.shape)         # (2, 1): giữ trục để broadcast được
print(A / s)           # chia mỗi hàng cho tổng của nó
```
