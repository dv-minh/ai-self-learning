```python
import numpy as np

X = np.zeros((4, 3))    # 4 mẫu, 3 đặc trưng
w = np.zeros(3)

print((X @ w).shape)    # đúng: (4,)
print((w @ X).shape)    # sai thứ tự: 3 không khớp 4
```

