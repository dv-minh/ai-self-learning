```python
x = 2
w = 1
b = 1
y = 5

z = w * x + b
a = max(0, z)
L = (a - y) ** 2
```

Forward: $z = 3$, $a = 3$, $L = (3 - 5)^2 = 4$.

$$
\dfrac{\partial L}{\partial a} = 2(a - y) = -4
$$

$$
\dfrac{\partial L}{\partial z} = -4\cdot \mathrm{ReLU}'(z) = -4\cdot 1
$$

$$
\dfrac{\partial L}{\partial w} = -4\cdot x = -8,\qquad \dfrac{\partial L}{\partial b} = -4\cdot 1 = -4
$$
